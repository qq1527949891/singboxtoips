mip-proxy 0.1.6

长期运行稳定性修复：代理、订阅与回落页退出后每 5 秒重启，取消连续启动失败后的永久限流；依赖启动失败会继续重试，手动停止/重启仍正确传递到依赖服务。添加每服务日志速率限制与辅助服务文件描述符限制。

为 HTTPS 订阅和 Trojan 本机回落页添加 64 连接上限、完整读取/写入/空闲超时，避免慢请求体与未完成的 TLS 握手长期占用资源。辅助服务退出会关闭连接并清理取消回调；不限制代理核心的节点连接数量。

缓存订阅导出与 TLS 证书，避免每个请求重复生成所有节点、每个握手重复扫描与验证证书。配置/令牌更新立即失效；证书每秒至多检查一次，续期写入短暂失败时保留有效旧证书，但拒绝过期证书。

新增并发竞态检查、服务反复启停与慢请求测试、订阅状态替换/损坏/恢复、证书续期与过期测试；通过 sing-box 和 Mihomo 客户端，对全部 8 种协议合计执行 1536 次 TCP 短连接和 1536 次 UDP 关联，验证双 IP 出口。测试等待客户端转发就绪，消除仅等待监听端口引起的启动竞态；压力阶段不重试失败请求。

GitHub CI 在真实 systemd 上测试生成的服务单元，注入路由不可用、连续八次正常退出、SIGKILL 和手动依赖重启/停止。使用临时独立单元与桩程序，不修改主机网络；本地无 systemd 环境明确跳过。

升级后请在向导执行“创建/更新节点”，安装新服务单元并重启运行中的服务。短时测试不等同于数周运行验证，不保证第三方核心不会发生故障。

以下为 v0.1.5 更新：

修复自定义 Trojan 代理 TCP 端口为 8443 等推荐值时，HTTPS 订阅可能选中同一端口导致部署失败的问题。端口选择同时检查现有监听与新配置将创建的代理监听；离线预览也会预留代理端口，并识别 IPv4 映射的 IPv6 监听。

修复所有推荐订阅端口被占用时，高级向导提前退出、无法输入其他端口的问题。现在可直接指定其他端口；误填 TCP 80 或代理 TCP 端口时会提示重新输入。

修复更新部署时漏停自动重启等待中的旧服务的问题。配置替换前显式停止本工具的全部服务，取消排队的重启，避免旧服务在更新中重新启动。

安装脚本兼容紧凑 JSON 格式的 Release 信息，并补全 gzip 依赖检查。保留公开仓库免令牌下载方式。

新增以上问题的回归测试和真实 Linux TCP 监听端口选择测试；保留全部协议、双 IP 出口、IPv6、ACME、HTTPS 订阅、路由、回滚与安装验证。

以下为 v0.1.4 更新：

WireGuard 的控制台输出改为 Mihomo/Clash 单行 YAML 节点格式，每个 IP 一行，使用实际节点的公网 IP、映射/分配端口、客户端私钥与服务端公钥。包含 IPv4 路由、保活、远程 DNS 和 MTU；未配置的预共享密钥不虚构输出。原生 .conf 文件仍保留。

Trojan、Hysteria2、TUIC、WireGuard 向导部署后自动打印可访问的 HTTPS 订阅地址：Mihomo 完整配置、proxy-provider、sing-box 配置；前三种另有通用 URI/Base64，WireGuard 另有逐 IP 的原生 .conf 下载地址。256 位随机令牌保护访问，不公开状态、备份或服务端私钥。

订阅优先使用 UDP 协议的 TCP 443、Trojan 的 TCP 8443，自动避开已存在的 TCP 监听。已有部署保留端口和令牌。需在防火墙/安全组/NAT 放行实际订阅 TCP 端口；自动证书的 TCP 80 仍需持续允许公网访问。mip-proxy subscriptions 可以重新查看地址。

订阅复用自动续期的 IP 证书，WireGuard 也可无域名申请 HTTPS 证书。新增独立订阅服务、事务回滚和私有证书管理，续期后无需重启订阅服务。只读加锁兼容 systemd 的 ProtectSystem=strict。

新增 HTTPS 访问控制、证书更新、只读挂载与服务生命周期测试，真实 ACME 的 WireGuard 证书申请测试，以及使用控制台打印的 WireGuard 节点进行 Mihomo TCP/UDP 转发验证。

以下为 v0.1.3 更新：

部署成功后，控制台末尾直接打印全部节点。SOCKS5 使用 IP/端口/用户名/密码；Shadowsocks（SS）使用 IP/端口/aes-256-gcm/密码。VLESS、VMess 保留现有分享链接，Trojan、Hysteria2、TUIC 使用标准链接，WireGuard 输出原生客户端配置。标准订阅文件格式继续保留。

以下功能同时包含在此版本中：

普通部署向导只选择协议，其余可确定设置自动采用推荐值：全部 IP、443 监听端口、网卡/网关对应的路由方式、已有节点凭据。已有部署保留原端口。自定义设置可使用 mip-proxy wizard --advanced；预览可使用 --out。

Trojan、VMess、Hysteria2、TUIC 默认自动申请可信的免费公网 IP 证书并自动续期，无需购买域名或填写证书文件。验证 IP 的 TCP 80 必须允许公网访问。私钥只保存在服务器，客户端 TLS 验证保持开启。

签发前检查 TCP 80 冲突；部署等待可信证书就绪后才导出节点，失败会回滚。使用 P-256 密钥和 shortlived 证书配置，核心自动续期和加载证书。

新增真实 ACME HTTP-01、IP 证书与四种 TLS 协议双 IP 转发测试，使用固定版本的 Pebble 测试 CA，测试证书不会用于生产。

以下为 v0.1.1 更新：

Debian 12+ 多 IP 单协议代理节点工具，支持 SOCKS5、Shadowsocks、VMess、VLESS + REALITY、Trojan、Hysteria2、TUIC、WireGuard。

修复 IPv6 目标可能使用系统默认出口的问题。正式部署自动禁用整台服务器的 IPv6，持久化 sysctl，并在每次代理服务启动前重新检查。部署失败或回滚时恢复原有开关、IPv6 地址和路由快照。
加强策略路由的归属检查，保留其他程序修改过的规则与路由。
修复损坏状态文件/导出清单导致恢复失败，以及取消节点检测后继续探测的问题。
修复重复公网 IP 导致客户端节点名称冲突、空状态文件被当作正常结束的问题。

安装脚本自动识别 amd64/arm64：优先使用本地安装包中的程序；单独运行时查询最新 Release，已安装同版本则复用，否则下载对应安装包并验证 SHA256。

下载 install.sh 后执行 sudo sh install.sh。环境变量 MIP_VERSION=v0.1.1 可固定版本。
每次交互只选择一种协议，所有 IP 节点统一使用该协议。
